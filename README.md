# ChordPro 所見即所得編輯器

不用寫程式碼，直接在譜面上編輯的 ChordPro 和弦譜編輯器。
譜面格式仿照 91pu：曲名置中、Key / Play / Capo / Tempo / 節奏資訊列、
上方和弦指法圖、歌詞上方紅色和弦。

## 啟動方式

雙擊 `啟動編輯器.command`（或直接雙擊 `index.html`）即可在瀏覽器開啟，
不需要安裝任何東西、不需要網路。內容會自動儲存在瀏覽器裡，下次打開繼續編輯。

## 操作方式

| 想做的事 | 操作 |
|---|---|
| 改曲名 / 歌手 / Key / Capo… | 直接點標頭文字輸入 |
| Key / Play / Capo 連動 | 維持 **Key = Play + Capo**：改 Capo → Key 重算（指法不變）；改 Play → 譜面和弦移調到新調、Capo 重算（Key 不變）；改 Key → Capo 重算（Play 不變） |
| 移動和弦位置 | 用滑鼠**拖曳**和弦，放到任何字的上方（可拖到別行） |
| 新增和弦 | 點歌詞上方的空白處，輸入和弦名（有自動提示；升降記號 `#C` 或 `C#` 都認得）。也可以**直接輸入級數**：`4`→F、`2m7`→Dm7、`57`→G7、`5/7`→G/B（以 Play 調換算） |
| 順階和弦面板 | 依 Play 調、**每個級數一欄縱向對齊**。平常只顯示順階一排（1～6m＋小節線）不佔版面；**滑到某一級**＝該級的延伸選項往上展開（如 1 級：1maj7、1add9、1sus4、1/3、17）；按右側「⌃」＝整面矩陣展開。顏色代表常用度：**綠＝最常用、黃＝次之、白＝較少用**。拖到譜上任意位置放置；編輯歌詞時點一下＝插入到游標處；改 Play 調即時更新。**拖曳左側「順階」標籤可移動整個面板**，位置會記住 |
| 和弦上方顯示指法圖 | 點一下和弦 →「顯示圖示」，這個和弦的上方就會出現小指法圖（每個和弦可個別開關），列印與匯出（`[C*]`）都會保留 |
| 調整顯示大小 | 工具列右側三條滑桿：**字級**（歌詞與和弦字體）、**和弦圖**（最上方指法圖）、**行內圖**（歌詞行內指法圖） |
| 插入小節線 | 小節線顯示在**和弦那一行**（91pu 樣式）。點歌詞上方的空白處 → 按「小節線｜」（或輸入 `|`）；編輯歌詞時直接打 `|` 也會加在游標處的和弦列。可拖曳移動、點一下可刪除 |
| 改名 / 刪除和弦 | 點一下和弦 |
| 自訂和弦按法 | 點上方的和弦指法圖：點格子＝按壓位置、**Shift+點＝同一弦加另一個音**（空心圓）、點琴枕上方＝切換 ○ 空弦 / × 悶音，可設起始把位（封閉和弦）；下方可填**指法代號（T、1～4，低音E→高音E）**，會畫在按壓點裡；上方的和弦名稱可直接修改，整首歌會一起改名。圖預設 3 格，按法超出會自動加大 |
| 貼上整首歌詞 | 工具列「貼歌詞」→ 直接貼文本，依換行自動分行（可附加或取代） |
| 編輯歌詞 | 完全所見即所得：游標直接顯示在譜面上、打字即時更新、**和弦全程可見**並跟著字移動；點哪個字游標就在哪、**Enter** 拆行、**行首 Backspace / 行尾 Delete** 併行、**↑↓** 移到上下行、Esc 還原本行、點其他地方結束編輯 |
| 看出和弦對到哪個字 | 有和弦的字會以淡橘色底＋橘線標示；滑鼠移到和弦上，對應的字會加深 |
| 長句歌詞 | 超過頁寬會自動換行，和弦跟著字一起換行 |
| 段落標題（主歌/副歌…） | 「＋ 段落標題」按鈕，點標題可改名 |
| 插入 / 刪除 / 上下移動行 | 滑鼠移到行右側出現的小按鈕 |
| 純和弦行（前奏/間奏） | 新增空歌詞行後，直接在上方點擊放和弦 |
| 移調 | 工具列「移調 ±1」，Key / Play / 自訂指法會一起移（自訂按法的按壓位置整體平移） |
| 級數和弦 | 工具列「級數」切換：以 **Play** 調（沒填則用 Key）為 1 級顯示級數（Play G 時 G=1、Am=2m、C=4、D/F#=5/7…）。純顯示切換，資料與匯出仍是字母和弦；改 Play 調會即時重算 |
| 匯入 / 匯出 | 工具列「匯入」「匯出 .cho」，標準 ChordPro 格式，可與其他軟體互通 |
| 看 / 改原始碼 | 工具列「原始碼」 |
| 印成紙本譜 | 工具列「列印」（會自動隱藏編輯介面） |

## 檔案說明

- `index.html` — 主頁面
- `app.js` — 編輯器邏輯（拖曳、指法編輯器、渲染）
- `chordpro.js` — ChordPro 格式解析與輸出
- `chords.js` — 內建和弦庫（含封閉和弦自動推算）與移調
- `style.css` — 樣式（含列印樣式）

自訂按法會以標準的 `{define: 名稱 base-fret N frets ...}` 指令存進 .cho 檔。
